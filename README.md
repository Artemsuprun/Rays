# Rays

A browser-based raycasting system built with JavaScript and HTML Canvas API. This project explores the fundamentals of real-time rendering by transforming a 2D environment into a pseudo 3D first-person perspective.

## Overview

The program renders the environment from two perspectives:

- 2D Map: A top down view of the world, including the player, walls, and rays.
- 3D Map: A first-person perspecitve generated by casting rays into the environment and calculating wall distance.

This shows us how a three-dimensional effect can be created using two-dimensional geometry and rendering techniques.

## How Raycasting works

Raycasting is a rendering technique that projects rays from the player's position into the environment to determine the distance to nearby walls.

The process is:
1. Cast rays from player's field of view.
2. Calculate where each ray intersects a wall.
3. Determine the distance from the player to each intersection.
4. Convert those distance into vertical wall slices.
5. Render the slices to create a pseudo 3D perspective.

Walls closer to the player appear taller, while further away appear shorter. this creats an illusion of depth without needing a full 3D engine.

## Technologies

- JavaScript: Game logic, raycasting calucations, and rendering.
- HTML Canvas: Drawing the map and first-perion perspective.
- HTML/CSS: Browser interface and page layout.
